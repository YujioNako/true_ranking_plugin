计算方法与结果说明

沿用原油猴脚本：每条评论等权，合并长短评计算算术平均分；最低用户等级默认 5，可在 0–6 之间调整。两类评论分别去重，同一用户的长评与短评仍分别计数。

采集结束仅表示接口可见分页已读完，不表示拿到了全部评分。采集 / 官方标称比例使用合并评论数除以官方评分人数，两者口径不同，可能超过 100%。评论并非随机样本，结果仅供参考，不代表客观「真实评分」。

趋势按每组样本的最早日期起划分 8 个区间，累计计算，超过两年的评论不进入趋势图，但仍计入总均分。两组的日期范围可能不同；所有评论同一天时显示一个点。

置信度沿用原脚本的正态近似与有限总体校正：合并样本以官方评分人数为标称数，短评、长评分别以对应接口标称数计算；过滤前后沿用同一个标称数。有效样本不足 2 条、标称数未知或为 0 时显示「暂不可估」。样本数达到标称数或样本评分完全相同时，原公式返回 100%，并不表示结果没有误差。

标准误 SE = √[s² / n × (N − n) / (N − 1)]，模型概率 = 2Φ(0.1 / SE) − 1。其中 s² 是样本方差，n 是有效样本数，N 是对应标称数，Φ 是标准正态分布的累积分布函数。
